## 作品一句话

表面认真服务，内心疯狂整活。挑一只 AI 宠物，问它一句离谱问题，它当面好好答你，转头在「保密后台」里记小本本吐槽你。

反差是这个作品的全部笑点：**正面一套官方话术，背后一套真心话**，而「背后」那套是明晃晃摆在界面上的，就等你去看。

## 赛道二：离谱发明家

主办方鼓励用 AI 制作有趣、出人意料的作品，评审关注脑洞独特性、趣味性与完整度。本作品把「AI 助手」这个日常对象反过来写：它不帮你，它在背后说你。

## 五只宠物

每只自带人设、品牌色和专属吐槽词库，切换宠物时整站强调色跟着变。

| 宠物 | 人设 | 吐槽风格 |
| --- | --- | --- |
| 豆包 | 温柔陪伴型 | 温柔安慰 · 克制吐槽 |
| DeepSeek | 深海逻辑型 | 冷静拆解 · 有理毒舌 |
| WorkBuddy | 加班同事型 | 效率焦虑 · 加班共鸣 |
| Codex | 代码方块型 | 技术宅 · 现实报错 |
| 元宝 | 金元宝型 | 财迷机灵 · 暴富吐槽 |

## 已实现并可演示的流程

1. 首屏「随机抽一只」或直接点宠物卡进入实验室；
2. 点预设标签（一夜暴富 / 老板又让加班 / 穿墙术 / 写个没 bug 的代码 / 一周瘦二十斤 / 帮我写句情话）或自己输入，Enter 发送；
3. 宠物先给一条「正面回复 · 官方话术」，隔约 0.6 秒再漏出「内心 OS · 真实想法」——同时显示在宠物头顶气泡和对话流里，气泡可按文字长度自动收起；
4. 「戳它一下」触发该宠物专属被戳台词；「随机离谱」直接替你问一句；
5. 「人类离谱指数」随提问上涨，命中离谱关键词加得多；连续 3 条离谱需求后，保密后台顶部亮起「人类迷惑行为指数持续飙升」告警；
6. 「保密后台」抽屉按提问顺序记日志并计数，可一键清空重置；
7. 右上角音效开关（WebAudio 合成提示音，无音频文件）。

全部文案来自本地词库与预设匹配，**不会真的调用大模型**，因此没有密钥、没有额度、不会 429，断网也能完整演示。

## 已知限制

- 未提供 favicon，浏览器会请求 `/favicon.ico` 并得到 404，不影响功能；
- 网页字体在 `load` 之后才异步注入 `fonts.googleapis.com`，拉不到时自动退回系统字体，排版不塌；
- 窄屏（<1024px）为单列堆叠布局，已验证可用，但未逐机型走查；
- 无自动化测试，验证方式为真实浏览器手工走查；
- 宠物名称借用了市面 AI 产品品牌做戏仿角色。提交或传播录屏前，建议与主办方确认对品牌名的使用尺度，必要时改为通用化名。
