## 赛道二：离谱发明家

根据主办方指南，本赛道鼓励用 AI 制作有趣、出人意料的作品，方向包含但不限于 AI 整活工具、反常识交互。评审重点关注**脑洞的独特性、作品的趣味性和完整度，以及是否能让人会心一笑**。

下一步围绕一个具体场景确定创意、AI 的实际作用和可稳定演示的核心流程。具体作品尚未确定；本仓库记录赛道选择，不代表已完成主办方报名或作品提交。

## 当前产品构想

「人类观察报告：人类研究中心」准备把普通的人类日常行为包装成一份一本正经的研究报告。用户主动提交例如熬夜、拖延、反复打开冰箱等行为，AI 以外星研究员、官方调查员或哲学观察员等视角进行善意吐槽，并给出荒谬但无害的改进建议。

这是当前的创意方向，不代表已经完成实现。产品应吐槽行为和情境，不针对真实身份、受保护群体或他人隐私。

当前 Demo 已加入一个赛道化互动：累计完成 5 次观察后解锁「闲着无聊」成就，状态保存在当前浏览器中；这项成就是演示用进度，不需要登录账号。

## 运行与配置（v2，已验证）

纯静态项目，无需安装依赖、无需构建：

1. **在线体验**：访问 GitHub Pages 链接（当前线上为 v1 旧版；`feat/ai-realtime-report` 合并后自动更新为 v2）。首次使用在引导卡粘贴一枚[智谱 BigModel](https://open.bigmodel.cn) 免费 API 密钥——密钥只保存在你自己的浏览器 localStorage，仓库与代码不含任何密钥。
2. **本地运行**：直接双击 `index.html`，或用任意静态服务器（如 `npx serve`）打开。
3. **无密钥体验**：引导卡点「先翻离线档案」，可浏览 7 条历史观察记录；429/断网/密钥无效时也会自动引导到该模式。
4. **自动化测试**：仓库根目录执行 `node --test`（需 Node ≥ 18），覆盖提示词契约校验（11 例）与错误分类、存储降级（6 例）。
5. **模型配置**：模型名是 `api-client.js` 里的常量 `API_MODEL`（当前 `glm-4.7-flash`），如官方调整模型线只需改这一行。

本项目不使用服务端密钥（无后端），因此没有 `.env.example`；设计详见 [docs/设计文档_人类观察报告v2.md](docs/设计文档_人类观察报告v2.md)。
