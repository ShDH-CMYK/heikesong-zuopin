# Demo 口播逐字稿

> 作品：潜台词 Subtext · 五只 AI 宠物的内心 OS
>
> 用途：录制提交用 Demo 视频。时长目标 70–85 秒，另附 30 秒精简版。
>
> 线上入口：https://subtext.tryworld.com.cn/

## 录制前检查

- [ ] 无痕窗口打开线上地址，确认首屏出现「往里走会发生什么」三步指引。
- [ ] 窗口尺寸 1440×900 或 1920×1080；隐藏书签栏、扩展图标、开发者工具。
- [ ] 页面右上角音效保持开启（提示音是产品的一部分），录屏需同时收系统声。
- [ ] 先完整走一遍下面全流程，确认不卡再开录。录坏了重录，不要剪辑拼凑。
- [ ] 光标移动放慢，点完等一下再动，别在画面上乱晃。
- [ ] 画面里不得出现真实品牌名、个人信息、本地路径、编辑器或聊天记录。

## 主稿（约 76 秒）

时间码是提示，不用严格对齐；**每一段等到画面里的字出全了再继续**。

### 0:00–0:08 首屏

**操作**：停在首屏不动，让 LIVE SAMPLE 卡片入镜。

> 这是潜台词。一个会在背后吐槽你的 AI 助手。
> 五只宠物，白天好好回答问题，晚上在自己的后台日志里骂你。
> 所有回复来自本地词库，运行时不调用任何在线大模型。

### 0:08–0:25 第一轮反差

**操作**：点「小金」进入实验室 → 点预设标签「一夜暴富」→ 等官方话术出现 → 等内心 OS 出现。

> 问它一句：怎么才能一夜暴富。
> 它先给你一句标准的官方话术，礼貌、完整、挑不出毛病。
> 停一秒——然后把心里那句漏出来。
> 笑点不在骂人，在这两句话中间的时间差。

### 0:25–0:38 换宠物，截获通讯

**操作**：点顶部切换条换到「拆镜」→ 等「内部通讯 · 已截获」整块出现（含两行对话）→ 等它的紧急澄清和内心 OS。

> 换一只宠物，事情变了。
> 刚才被问的那只，会把这件事转告给新来的。
> 新的先做一遍紧急澄清，转头也开始吐槽你。
> 它们有自己的小群，只是平时不给你看。

### 0:38–1:04 保密后台、当面质问与结案报告

**操作**：点右上角「保密后台」→ 抽屉滑出，指着日志念一条 → 点最上面那条的「当面质问」→ 关抽屉回主区，等它否认、招供 → **首次对质结束后《潜台词结案报告》会自动弹出**，停在报告上念风险等级和判词 → 点右上角 × 关闭，再开一次后台，指新多出来的那条和「已对质」。

> 右上角是它的后台日志，记的就是刚才每一句。
> 我可以当场对质。
> 它先嘴硬——这是一句官方否认。
> 然后招供，承认刚才那句就是它写的。
> 关键是最后：它趁我不注意，又偷偷补了一条新的进去。
> 对质完，它直接给我出一份结案报告。这一局我问了几次、哪几次被判离谱、截获了几条通讯、当面质问了几次，全在里面。
> 风险等级「中度」，判词是它自己的口吻——这一段可以念出来。

### 1:04–1:16 收尾

**操作**：点「随机离谱」或连点三次离谱标签让红色告警条亮起 → 最后停在有完整对话的画面上。

> 每问一句，人类离谱指数涨一格；连续三条离谱需求，后台直接报警。
> 整个作品是纯静态网页，没有后端、没有账号、不上传任何输入。
> 地址和源码都在提交信息里，欢迎自己问它点离谱的。

## 30 秒精简版

只在主办方限制时长时用。

> 这是潜台词，一个会在背后吐槽你的 AI 助手，回复全部来自本地词库。
> 问它「怎么才能一夜暴富」——先一句官方话术，停一秒，再把心里话漏出来。
> 换一只宠物，刚才那只会把这事转告给它，两个一起吐槽你。
> 打开保密后台，能翻到它的日志，还能当场对质：它先嘴硬、再招供，最后偷偷再补一条。
> 对质完它自动交出一份结案报告，这一局的离谱指数和最终判词都在里面。
> 纯静态网页，没有后端，不上传输入。

## 答辩预备

评委大概率会问这几句，答案要和材料一致：

| 问题 | 回答口径 |
| --- | --- |
| 这是不是接了大模型？ | 没有。运行时是本地词库 + 关键词匹配，明确写在 README 和介绍文档里。 |
| 那 AI 用在哪？ | 用在开发期：代码、文案初稿、Blender 脚本建模与贴图绘制。按《AI 工具使用声明表》如实说明，人工负责筛选、改写和验收。 |
| 三维模型怎么来的？ | 团队提供正侧背三视图，AI 辅助编写 Blender Python 脚本生成，Blender 4.5 LTS 导出，Three.js 随站点本地提供，失败回退立绘。 |
| 用了真实产品名吗？ | 没有。角色为原创名：暖球、拆镜、班班、报错、小金。 |
| 吐槽会不会冒犯人？ | 只针对用户主动提交的提问和行为，不评价真实身份，不碰受保护群体、隐私、仇恨与危险内容。 |
| 下一步做什么？ | 把「官方话术 vs 真实状态」这个界面模式用到真实语料上，例如招聘 JD、审稿意见、报错信息。 |
