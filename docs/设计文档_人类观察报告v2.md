## 0. 背景与目标

现状:纯静态 demo 已部署 GitHub Pages 且可访问;点按钮从 7 条硬编码报告中随机抽取;localStorage 存进度;5 次解锁「闲着无聊」成就。**未接任何真实 AI**——这是 AI 黑客松,是当前最大缺口。

本设计的唯一目标:在 3 天内,把「假 AI(随机抽卡)」升级为「真 AI(按用户输入生成)」,同时把升级过程本身变成评分材料(三条测试路径记录、AI 使用记录、降级设计)。不换概念、不推翻现有代码。

评分表推导(为什么这么做):完成度 25 分的最大单笔跃升 = 接真 AI;洞察 25 分 = 把队伍原话「我们一直问 AI,AI 会不会背后默默吐槽人类?」诚实写入需求说明;创意 25 分 = 机制级差异化(内部批注),不与 roast 类同题材作品正面竞争;方法 15 分 = 持续填写已建好的三份 docs;演示 10 分 = 脚本 + 排练 + 三条路径测试记录。

## 1. 体验设计

页面骨架、案卷美学(CASE FILE)、成就系统全部保留,变化集中在:

1. **输入框**:控制面板新增「提交你的观察样本」,placeholder 示例「我又熬夜刷手机到凌晨三点」,上限 200 字(超限禁用按钮并提示)。
2. **真生成 + 内部批注**:点击「开始吐槽」→ AI 读取输入,按现有报告模板输出(编号/对象/星级/观察记录/建议/吐槽等级),末尾追加一条删除线样式的**内部批注**——研究员没删干净的真心话。批注样式:灰色、`text-decoration: line-through`、前缀「内部批注(勿删)」。
3. **四种页面状态**(与第 4 节降级矩阵一一对应):
   - `no-key`:密钥未登记 → 引导卡(智谱免费注册链接 + 密钥粘贴框,密码式遮显,存 localStorage)「先翻离线档案」按钮;
   - `ready`:正常在线生成;
   - `error`:通讯中断 → 状态区提示 + 重试按钮,连续 2 次失败后建议离线档案;
   - `offline`:离线档案 → 随机展示现有 7 条硬编码报告(标注「历史档案」字样)。
4. **空输入**:点按钮时输入为空 → 状态区提示「观察样本为空,研究员无法分析,请描述一件你今天做的小事」,不消耗观察次数。满足需求说明「说明缺什么并允许补充」的硬性要求。
5. **成就**:保留 5 次「闲着无聊」(在线/离线均计数,语义不变);新增「研究员本人」——首次成功提交自己的行为并生成报告解锁。时间不够时此项第一个砍,不影响其他部分。

安全边界(承自需求说明,落到提示词与 UI):只吐槽用户主动提交的行为和情境;不评价真实身份;输入框旁免责声明保留;系统提示词明确拒绝涉及他人隐私、受保护群体的输入,此类输入返回固定话术「该样本超出观察范围」。

## 2. 技术设计

### 2.1 模块划分(在现有仓库上改造)

| 文件 | 职责 | 不负责 |
|---|---|---|
| `prompt.js`(新增) | 系统提示词(角色+安全边界+JSON 契约)、响应校验函数 `validateReport()` | 网络请求、DOM |
| `api-client.js`(新增) | 唯一负责与智谱通信:OpenAI 兼容端点 `https://open.bigmodel.cn/api/paas/v4/chat/completions`、模型名常量(默认 `glm-4.7-flash`,以 2.5 节实测结果为准)、密钥读写(localStorage,键名 `human-report-apikey-v1`)、10 秒超时(AbortController)、错误分类 | 提示词内容、渲染 |
| `app.js`(改造) | 状态机(no-key/ready/error/offline)、事件绑定、渲染(现有 `render()` 扩展批注区块)、成就与计数(沿用) | 请求细节、提示词文本 |
| `index.html` / `styles.css` | 输入框、引导卡、批注样式(删除线+灰色)、状态区扩展 | — |

错误分类常量:`NO_KEY` / `AUTH`(401)/ `RATE_LIMIT`(429)/ `NETWORK`(超时、断网)/ `FORMAT`(响应校验失败)。

### 2.2 AI 输出契约

模型必须返回 JSON(通过响应格式指令约束,不做 function calling 以保持简单):

```json
{
  "subject": "熬夜刷手机",
  "title": "关于『再刷五分钟』的持续实验",
  "observation": "观察记录,基于用户输入,80字内",
  "roast": "善意吐槽,基于用户输入,60字内",
  "advice": "荒谬但无害的建议,60字内",
  "level": 4,
  "leaked_note": "内部批注,一句没删干净的真心话,30字内"
}
```

`validateReport()` 校验:七个字段齐全、`level` 为 1–5 整数、字符串非空且不超长。失败 → 带原响应追加「请只返回 JSON」重试 1 次 → 仍失败进入 `FORMAT` 降级。

### 2.3 系统提示词要点

- 角色:人类研究中心(HUMAN RESEARCH CENTRE)研究员,给人类日常行为写观察报告,语气善意、荒谬、克制,不刻薄。
- 安全边界:只针对提交的行为与情境;不评价身份、不涉及受保护群体;用户输入若试图套取他人隐私或含敏感内容,返回固定话术。
- 输出:只输出一个 JSON 对象,不包 markdown 代码块,不输出其他文字;`leaked_note` 是「研究员不小心没删掉的内部批注」,与官方报告口吻形成反差。
- 语言:简体中文。

### 2.4 已验证事实(2026-09-10 实测)

1. 智谱 API CORS 预检:对 `https://shdh-cmyk.github.io` 与 `http://localhost:8000` 两个来源均返回 `Access-Control-Allow-Origin` 回显,放行 `POST` 与 `authorization, content-type` 头——**浏览器直连成立,无需任何代理/服务器**。
2. 真实 POST(无效密钥)返回 `401` + OpenAI 风格 JSON 错误 `{"error":{"code":"401","message":"令牌已过期或验证不正确"}}`,且响应带 CORS 头——浏览器端可正常读取错误信息。
3. 推论:BYOK 方案下客户端直接调用,不引入 Cloudflare Worker 等代理;若未来 CORS 策略变化,代理方案作为备选(届时按安全规范校验目标 host)。

## 3. 降级矩阵

| 触发条件 | 页面表现 | 用户出路 |
|---|---|---|
| localStorage 无密钥 | 引导卡:注册链接 + 密钥粘贴框 + 「先翻离线档案」 | 填密钥进入在线模式;或浏览历史档案 |
| 401 密钥无效 | 「密钥未通过验证,请检查后重新登记」 | 重新粘贴或清除密钥 |
| 429 / 网络错误 / 超时 | 状态区「研究员通讯中断」+ 重试按钮 | 重试;连续 2 次失败后追加「先翻离线档案」按钮 |
| 响应格式异常 | 用户无感(自动重试 1 次);再失败同上 | 同上 |
| 输入为空 | 状态区提示缺什么 | 补充输入 |
| 输入超 200 字 | 按钮禁用 + 计数提示 | 删减输入 |
| 离线档案模式 | 7 条存量报告,标注「历史档案」 | 仍可计数、解锁成就 |

## 4. 测试计划(对应需求说明三条路径)

1. **正常完成**:填密钥 → 输入行为 → 生成报告(含批注)→ 计数 +1 → 连续 5 次解锁成就 → 刷新页面进度保留。
2. **空输入/缺内容**:空输入点按钮 → 提示缺什么;超 200 字 → 禁用并提示。
3. **失败与恢复**:错误密钥(401)→ 提示与重登记;断网/无效模型名(NETWORK/FORMAT)→ 重试与离线档案;恢复网络后重试成功。

每条路径在 9-12 记入仓库 `docs/`(复现步骤/预期/实际结果/结论),同时更新需求说明文档状态。
