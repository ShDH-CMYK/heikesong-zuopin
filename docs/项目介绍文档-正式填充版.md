## 一、项目概览（ 一句话说清 ）

**项目名称：** 潜台词 Subtext · 五只 AI 宠物的内心 OS

**介绍：** 选择一只性格不同的 AI 宠物，提出一个离谱问题。它先给出礼貌的官方回复，随后在头顶气泡和保密后台日志中公开真实吐槽。五个角色可旋转、缩放、点击互动，并通过内部通讯、告警和结案报告把一次提问变成可继续探索的反差体验。

## 二、为什么做（Why）

**受众是谁？** 喜欢 AI、互动网页和轻度整活的学生及年轻用户。他们在浏览器中遇到作品，通常只需要几十秒就能理解并尝试。

**想创造什么？** 我们把 AI 助手通常隐藏的“后台真心话”变成可见体验。用户先看到认真回答，再看到延迟出现的内心 OS，能在一次提问中感受到角色差异和反常识笑点。

**现有体验还缺什么？** 普通问答只展示结果，聊天机器人整活又常常没有持续反馈。本作品加入角色切换、内部通讯、保密日志、连续离谱告警和结案报告，让一次回复形成完整闭环。

## 三、做了什么（What）

### 功能 1：官方回复与内心 OS

**设计意图 / 解决的问题：** 用约 0.6 秒的回复延迟制造“表面认真、随后吐槽”的反差。预设问题和自由输入都能生成用户提问、官方回复和角色专属内心 OS。

**关键截图 / 流程：** 选择宠物 → 点击预设问题或输入问题 → 查看官方回复 → 等待内心 OS 气泡和消息出现。

### 功能 2：五角色 3D 互动与内部通讯

**设计意图 / 解决的问题：** 让角色从图片变成可探索的实体。五个 GLB 支持拖动旋转、滚轮或双指缩放、视角复位、Idle 待机和 React 点击动作；换宠物后可截获内部通讯。

**关键截图 / 流程：** 进入实验室 → 拖动模型查看正侧背面 → 点击模型或“戳它一下” → 切换宠物查看内部通讯。

### 功能 3：保密后台与结案报告

**设计意图 / 解决的问题：** 把零散吐槽变成可追踪的记录。连续三条离谱需求触发红色告警；用户可打开后台查看日志并当面质问，首次对质后生成带统计和判词的结案报告。

**关键截图 / 流程：** 连续点击离谱标签 → 打开保密后台 → 查看红色告警和日志 → 点击当面质问 → 查看并复制结案报告。
