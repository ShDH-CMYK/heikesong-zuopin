# 三条路径测试记录(2026-09-10 起)

> 对应 `docs/需求说明.md` 的测试要求与设计文档第 4 节。每条路径记录:复现步骤 / 预期 / 实际 / 结论。
> 验证分两层:**API 管线级**(Node 直调 `requestReport`,等同浏览器发出的真实请求)与**浏览器端到端级**(页面交互)。下表如实区分,浏览器级结果由使用者验证后补充。

## 路径一:正常完成

- 步骤:登记研究员密钥 → 输入"我又熬夜刷手机到凌晨三点" → 点击「开始吐槽」
- 预期:生成含「内部批注」的实时报告;观察计数 +1;连续 5 次后解锁「闲着无聊」;刷新页面进度保留
- 实际(API 管线级,2026-09-10):
  - 模型 `glm-4.7-flash` 返回 200,免费额度可用;
  - 模型为思考型(本次 usage:reasoning_tokens 1180 / completion 1341),JSON 按契约干净输出在 `content` 字段,无围栏;
  - `extractJson` 解析成功,`validateReport` 七字段校验通过;
  - 生成样例(节选):观察对象「凌晨三点的蓝光像素奴隶」;内部批注「其实我也在刷，快睡吧。」——批注与官方报告形成反差,符合设计意图。
- 实际(浏览器端到端级,2026-09-10 自动化浏览器实录,提交 dba7344 版本):
  - 真实密钥登记后引导卡收起,状态"密钥已登记,观测站切换到实时分析。";
  - 提交样本后生成实时报告:kicker「人类观察档案 / 实时分析」、注脚「本条报告由 AI 研究员实时生成，仅供会心一笑。」、内部批注「其实我也经常在这个点刷手机。」(划线灰字样式经截图确认);
  - 计数 01→02,页脚同步;「研究员本人」成就自动 UNLOCKED(橙色高亮,截图确认);
  - 刷新后进度与密钥保留。
- 结论:**通过**(两层验证均通过)

## 路径二:空输入 / 缺内容

- 步骤 2a:输入框留空,点击「开始吐槽」
- 预期:状态区提示"观察样本为空…",不消耗观察次数
- 实际(浏览器端到端级,2026-09-10):提示「观察样本为空：请描述一件你今天做过的小事，研究员才能开始分析。」;计数保持 02 未消耗
- 步骤 2b:尝试输入超过 200 字
- 预期:输入框 maxlength 截断,计数显示 200 / 200
- 实际:键盘/粘贴输入受 maxlength 限制(HTML 标准行为);另发现程序化赋值可绕过 maxlength 使计数器显示"250 / 200",已于提交 573014e 修复(输入事件强制截断到 200)
- 结论:**通过**(2b 边缘情况已修复)

## 路径三:失败与恢复

- 步骤 3a(密钥无效):登记一个错误密钥 → 提交样本
- 预期:提示"密钥未通过验证…",引导卡重新出现,可重新登记
- 实际(浏览器端到端级,2026-09-10):真实 401 → 引导卡重现,错误提示「密钥未通过验证，请检查后重新登记，或先翻离线档案。」,计数未消耗;随后直接登记正确密钥即恢复在线
- 步骤 3b(限流/过载):提交样本,模型繁忙
- 预期:提示"研究所线路拥挤（触发限流），请稍后重试";连续 2 次失败后引导卡给出「先翻离线档案」
- 实际(API 管线级,2026-09-10):联调中智谱真实返回 429 + `{"error":{"code":"1305","message":"该模型当前访问量过大，请您稍后再试"}}`,`classifyStatus(429)` 映射为 RATE_LIMIT;高峰时段 4 次请求 3 次 429,证明限流频繁。**据实测已于提交 dba7344 增加自动退避重试(2 次,间隔 3 秒)**,重试后成功
- 步骤 3c(恢复):恢复后重试
- 预期:回到实时生成
- 实际(浏览器端到端级):修复超时后(原 10 秒超时会误杀 50 秒级的思考型生成,实测单次成功生成 50.1 秒,已改 60 秒),浏览器端一次提交即成功归档;离线档案切换此前亦实测通过(「历史样本」报告,计数+1)
- 结论:**通过**(3b/3c 暴露的两个真实问题均已修复并复测)

## 已知限制(如实声明)

- glm-4.7-flash 为思考型模型,单次生成实测可达 50 秒、约 1400 completion tokens;高峰时段(如晚间)429 频繁,客户端已自动退避重试 2 次,仍失败需手动重试或转离线档案;
- 超时为 60 秒(提交 dba7344),等待期间按钮显示"研究员分析中…";
- 多观察视角切换本轮未做;单测未覆盖 DOM 交互(浏览器级已人工+自动化实录);
- 浏览器级验证使用自动化浏览器驱动 DOM 事件完成,截图存档于开发过程材料。
