# 五角色三维交互

五个角色共用同一个 Three.js 画布、相机和交互控制器，每个角色加载独立的 GLB。角色内部 ID 沿用历史名称，页面仍显示暖球、拆镜、班班、报错和小金。

## 资产来源与范围

| 页面角色 | 资源 | 制作方式 |
| --- | --- | --- |
| 暖球 | `pets/doubao.glb` | 按原立绘的黑色短发、奶油色大衣、红围巾与裙装构建风格化体积 |
| 拆镜 | `pets/deepseek.glb` | 沿用上一版用户 Blue.rar 实体网格、PBR、骨骼和蒙皮，详见 [Blue 资产说明](DeepSeek三维模型.md) |
| 班班 | `pets/workbuddy.glb` | 青绿圆角电视头、疲惫面部、电量胸章与机械肢体 |
| 报错 | `pets/codex.glb` | 紫蓝方块机体、发光笑脸屏、耳机、代码屏与散热细节 |
| 小金 | `pets/yuanbao.glb` | 金色元宝头套、圆脸、金色身体与光环 |

新增四个角色是在 Blender 中按现有单张立绘进行的程序式风格化重建。它们包含真实厚度、侧面和背面，背面细节是根据造型推定的补建。单张图片不能唯一确定一个人物的三维结构；本轮不声称恢复了立绘的原始模型，也不把这四个模型描述为 Blue 同级高面数雕刻资产。

新增角色使用分件节点动画，拆镜保持骨骼蒙皮。它们共享 `Idle`（待机循环）与 `React`（点击播放一次）命名，动作结束回到待机。所有模型的网页格式为 glTF 2.0 GLB，正面朝 +Z，Y 轴向上。

## 操作

| 操作 | 行为 |
| --- | --- |
| 鼠标左键拖动、单指拖动 | 水平完整旋转并调整俯仰，可查看正面、侧面、背面、顶部与底部 |
| 滚轮、双指捏合 | 缩放当前模型 |
| 点击模型、「戳它一下」 | 当前角色专属回复与 `React` 动作 |
| 双击模型、「复位视角」 | 恢复正面和适配画幅的观察距离 |
| 方向键、`+` / `-`、Home | 画布获得焦点时旋转、缩放和复位 |
| Enter、空格 | 画布获得焦点时触发点击互动 |
| 加载失败后的「重试 3D」 | 重新请求当前角色模型，加载期间保留立绘 |

拖动、双指缩放和触摸取消不会当作点击。系统选择减少动态效果时，自动待机暂停，主动点击仍可播放一次动作。模型不在视口中或页面隐藏时停止绘制。

## 加载和失败恢复

运行时按角色缓存最多五份加载结果，保留一个 WebGLRenderer 和画布。切换时停止旧角色的 AnimationMixer，并恢复其基础变换，随后按新模型尺寸调整相机。每次选择带有版本序号，旧请求晚到或失败均不会覆盖最新选择。

模型下载使用带 AbortController 的 fetch，30 秒仍未完成时终止下载并保留立绘。失败或超时的缓存会失效，下一次选择或点击重试可真正重新下载。GLB 缓冲交给本地 GLTFLoader 和 Draco 解码器解析；不依赖外部模型服务。

## 复建与验收

Blender 可编辑工程为 `pets/organic-pets.blend` 和 `pets/robot-pets.blend`，构建脚本分别为 `tools/build-organic-pets.py` 和 `tools/build-robot-pets.py`。拆镜源工程与构建脚本保持独立。

从仓库根目录启动 HTTP 静态服务。安装 Playwright 和 Chromium 后执行：

```powershell
python tools/check-pet-interactions.py http://127.0.0.1:8000/
python tools/regression.py http://127.0.0.1:8000/
```

第一个检查五角色加载、动画、旋转缩放、缓存重用、延迟请求、失败重试、鼠标与真实触摸输入、手机布局；第二个检查完整对话、内部通讯、结案报告、清空和安全转义流程。

构建渲染与统计保存于 `output/all-pets-review/`，网页截图和专项结果保存于 `output/playwright/all-pets/`。离线渲染与程序检查分别证明外观和交互，应结合查看。发布后还需核对线上五个 GLB 与本地文件哈希以及实际页面加载状态。

当前这次更新的发布验证入口为 GitHub Pages。Cloudflare 地址只有在单独同步并核验后才能标记为已更新。
