依据：[We Young 黑客松 2026 选手指南](https://my.feishu.cn/wiki/GCwZwKKG9iZ5ZMkV86wcjjLDnqf)，2026 年 9 月 9 日读取。提交截止为 **2026 年 9 月 13 日 14:00**，即正赛 Day 5；以主办方后续更新为准。

## 主办方要求的提交材料

- [ ] 与队友确定一条参赛赛道。
- [ ] 准备可演示原型（Demo 视频 / 可访问链接），核心功能稳定、演示连贯。
- [ ] 复制主办方的项目介绍文档模板，完成必填章节、替换占位标题，确认评审可访问。
- [ ] 在公开 GitHub / Gitee 仓库上传完整源代码。
- [ ] README 写清项目简介、技术栈和经过验证的运行方式。
- [ ] 代码及公开材料中不包含真实 API Key、密码、Token 等敏感信息。
- [ ] 完整填写《AI 工具使用声明表》，列明工具、可确认的版本、用途及人机协作方式。
- [ ] 检查第三方代码、模型、数据与素材的合法来源及许可义务。
- [ ] 确认原型、文档与仓库链接可访问，并在截止前完成提交操作。

## 发布与演示准备

以下结合 Day 7 教学建议和比赛演示安排，用于提高可演示性。

- [ ] 测试正常、空输入、失败与恢复三条路径，记录真实结果。
- [ ] 如提供在线体验，在无痕窗口及另一台设备上验证核心流程。
- [ ] 如提供录屏，检查画面、声音与内容是否清楚。
- [ ] 准备 5 分钟演示与 2 分钟问答，成员能解释创意、实现、人机分工及关键选择。
- [ ] 写清已知限制，保留必要的创作与迭代记录。
