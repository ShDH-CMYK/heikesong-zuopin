## 7 问题与目标用户


## 8 解决方案与核心创新

```
潜台词把「AI 礼貌回答」反转成一条走得完的闭环：提问 → 官方话术 → 延迟出现的内心 OS → 换一只宠物会截获它们互相打小报告的内部通讯 → 打开保密后台翻日志 → 对某条记录点「当面质问」，它先嘴硬否认、再招供、最后趁你不注意偷偷补记一条 → 首次对质结束自动生成《潜台词结案报告》，把这一局的提问数、离谱指数、截获通讯、对质次数和最终判词收成一份可复制带走的档案；连续三条离谱需求还会让后台直接报警。五只宠物是面对同一问题的五种行为方式，各自有可旋转、缩放、点击反应的三维模型。核心创新不在台词多，而在把「官方话术 vs 真实状态」做成用户可以翻、可以质问、可以结案的界面。运行时全部使用本地词库与关键词匹配，不调用在线大模型，不收集或上传用户输入，无后端、无账号。
```
