# 演示脚本(5 分钟演示 + 2 分钟问答)

> 设计原则(来自 Stupid Hackathon 获奖规律调研):**前 30 秒必须出第一个笑点**。
> 关键约束:AI 单次生成实测可达 50 秒,所以**现场生成要提前点火,等待时间用讲解填满**。

## 演示前检查(提前 10 分钟)

1. 演示机提前登记研究员密钥,并**预生成一份报告**留在页面上(不要刷新掉)。
2. 验证在线链接可访问(无痕窗口);录屏备份视频放在本地,网络崩溃时直接播放。
3. 关闭无关标签页和通知;浏览器缩放调到评委能看清字号。

## 演示流程

### 0:00–0:30 开场 + 第一个笑点(核心记忆点)

- 开场白:"我们队一直在想一件事——我们天天问 AI 问题,**AI 会不会在背后默默吐槽人类?**所以我们造了一个人类研究中心。"
- 指着预生成的报告,直接念**划掉的内部批注**(如"其实我也经常在这个点刷手机。"):
  "看报告最后一行——研究员没删干净的内部批注。**吐槽我们的不是别人,是 AI 自己。**"

### 0:30–1:30 现场生成(提前点火,边等边讲)

- 立刻在输入框提交一个新样本(问评委要一个,或用"设了五个闹钟还是迟到了"),点击开始吐槽。
- 等待期间讲(约 1 分钟,刚好填满):
  - "用户提交行为,AI 以人类研究中心研究员的身份生成正式观察报告——编号、星级、观察记录、荒谬建议。"
  - 安全边界:"它只吐槽行为,不评价人;系统提示词里写死了,涉及隐私直接拒收。"
  - 人机分工:"代码是我们和 AI 结对写的,提示词和降级设计是人拍板的。"

### 1:30–2:30 报告揭晓 + 成就系统

- 报告出来后**先读吐槽引用,再读内部批注**,停两秒让笑点落地。
- 滚到成就档案:"连续观察 5 次解锁『闲着无聊』;第一次提交自己的行为解锁『研究员本人』——你看,已经亮了。"

### 2:30–3:30 失败也是世界观(工程完整度)

- "高峰期研究员真的会忙不过来,我们做了三层兜底:自动重试、通讯中断提示、离线历史档案。"
- (可选,时间够才做)断网演示:提交后收到"研究员通讯中断",点「先翻离线档案」照样有报告——"**在这个世界观里,连故障都是剧情。**"

### 3:30–4:30 一句话总结

- "别的 AI 吐槽工具毒舌你的作品,我们让 AI 用一本正经的公文,善意地研究你的生活——而且 AI 自己也会在批注里露馅。"

### 4:30–5:00 收尾

- 指屏幕:"链接在提交材料里,评委可以提交自己的行为。小心批注。"

## 问答准备(2 分钟)

| 可能问题 | 答案要点 |
| --- | --- |
| AI 在哪里参与? | 报告内容 100% 由 GLM-4.7-Flash 实时生成;系统提示词约束人设+安全边界+JSON 输出契约;客户端校验后渲染 |
| 密钥安全? | 使用者自填、只存自己浏览器 localStorage;仓库零密钥(已 grep 排查);无后端 |
| 生成慢怎么办? | 思考型模型实测最长 50 秒;已做 60 秒超时 + 429 自动退避重试 2 次 + 离线档案兜底 |
| 和别的 AI 吐槽有什么区别? | 针对"行为"而非作品;统一虚构机构世界观;善意克制(不评人);内部批注是机制级差异 |
| 安全边界怎么保证? | 提示词强制(越界输入返回固定话术)+ 输出 JSON 校验 + 前端免责声明;输入不落库 |
| 后续计划? | 多观察视角(外星研究员/哲学观察员)、分享海报、样本库 |

## 风险与预案

- 现场 429 持续失败 → 讲解降级设计(这本身是加分项),播放备份录屏。
- 演示机故障 → 备用机同一账号已登记密钥。
- 批注内容不佳 → 多提交一次("研究员今天状态一般,再给他一次机会"也是梗)。
