# 需求说明：AI 后台吐槽日志 · 五只 AI 宠物的内心 OS

> We Young 黑客松 2026 · 赛道二「离谱发明家」 · 人民当家作组
>
> 状态：初稿（2026-09-11）。核心流程已实现并通过真实浏览器实测；标注「待确认」的事项需团队在提交前补齐。

## 一、作品一句话

挑一只 AI 宠物，问它一句离谱问题：它当面给你一套滴水不漏的官方话术，转头在自己的「保密后台」里疯狂吐槽你——而那个后台，是明晃晃摊在界面上的，就等你去点。

## 二、目标用户与使用场景

- 用户：日常高频使用 AI 助手的人（学生、开发者、打工人），以及黑客松现场评委与观众；
- 场景：用户已经非常熟悉「AI 礼貌、克制、滴水不漏」的对话。作品故意把反差摆上台面——**正面一套官方话术，头顶气泡与「保密后台」里同时漏出真心话**；
- 现场：3 分钟内可完整玩一遍，笑点不依赖任何前置操作。

## 三、要解决的问题

AI 助手在产品里永远只展示一种面孔——礼貌、正确、无懈可击，用户看不到「它背后怎么想」。本作品把那「背后的一面」从彩蛋升级成正文：宠物头顶的内心 OS 气泡、顶栏的保密后台日志，全都在等你戳穿。

## 四、最小版本范围（已实现）

### 核心演示流程（60 秒版）

1. 首屏点「随机抽一只，直接开问」，或直接点任意宠物卡进入实验室；
2. 点一个预设话题（一夜暴富 / 老板又让加班 / 穿墙术 / 写个没 bug 的代码 / 一周瘦二十斤 / 帮我写句情话），或自由输入后 Enter 发送；
3. 宠物先给「正面回复 · 官方话术」，约 0.6 秒后漏出「内心 OS · 真实想法」——同时出现在头顶气泡和对话流里，气泡按文字长度自动收起；
4. 「戳它一下」触发该宠物专属被戳台词；「随机离谱」直接替你问一句；
5. 「人类离谱指数」随提问上涨，命中离谱关键词（暴富、穿墙、一周……）涨得更多；
6. 连续 3 条离谱需求后，「保密后台」顶部亮起「人类迷惑行为指数持续飙升」告警；
7. 打开「保密后台」抽屉：按提问顺序的日志、条数计数、一键清空。

### 功能清单

| 能力 | 说明 |
| --- | --- |
| 五只宠物 | 豆包 / DeepSeek / WorkBuddy / Codex / 元宝，各自人设、品牌强调色、专属词库；切换时整站强调色跟着变 |
| 双通道输出 | 官方话术 + 内心 OS，气泡与对话流双处呈现 |
| 离谱指数 | 提问累计上涨，离谱关键词加权 |
| 保密后台 | 日志、计数、告警、清空 |
| 音效 | WebAudio 实时合成提示音，无音频文件；右上角可一键静音 |
| 响应式 | 宽屏双栏、窄屏单列 |
| 零依赖 | 纯静态 HTML/CSS/JS，无构建、无包管理、无外部接口 |

### 明确不做（本期）

- 不接真实大模型或任何在线服务——保证无密钥、无额度、断网也能完整演示；
- 不做登录、账号、云端存档；
- 不做移动端 App / 小程序（浏览器即全部）。

## 五、验收记录

- 2026-09-11 真实浏览器（Chromium）实测全流程通过：选宠物 → 预设/自由提问 → 官方话术 + 内心 OS → 戳一戳 → 随机离谱 → 连续离谱触发后台告警 → 后台日志与计数 → 清空重置；音效开关正常；
- 2026-09-11 换库后二次回归（真实浏览器）：切换宠物与整站强调色联动、返回首页、随机抽一只、自由输入、连续 3 条离谱触发告警、后台抽屉开合与计数、清空重置、音效开关均通过；控制台 0 报错；
- `file://` 双击直接打开可用（普通脚本，非 ES module）；
- 窄屏（约 724px 视口）单列布局可用；
- 无功能依赖的网络请求（字体为加载后异步注入，取不到自动退回系统字体）；favicon 为内联 data URI，不产生 `/favicon.ico` 请求；
- 仓库内无密钥、无 .env、无会话数据；
- 2026-09-11 线上部署（Cloudflare Pages <https://heikesong-zuopin.pages.dev/>）实测：首屏五张宠物卡、立绘加载、进实验室提问、内心 OS 与后台计数均正常；控制台 0 报错；
- 无自动化测试，以上均为真实浏览器手工验证。
