一句话定位：帮助**无聊又自嘲的普通人**在**摸鱼或深夜刷手机的间隙**完成**一次"被一本正经地研究"的会心一笑**。

## 当前创意草案（v2，已实现核心）

用户提交一件自己的日常行为（一句话，≤200 字），系统调用智谱 GLM-4.7-Flash，以"人类研究中心研究员"的统一视角实时生成一份包含"行为编号、观察对象、吐槽星级、观察记录、善意吐槽、荒谬改进建议"的报告，报告末尾附一条划掉样式的「内部批注」——与官方口吻相反的真心话，呼应"AI 在背后默默吐槽人类"的原始好奇。多观察视角（外星研究员/官方调查员/哲学观察员切换）为 v2 明确不做、列入已知限制。

互动成就：每次成功生成或调阅报告计为一次观察；累计 5 次时解锁「闲着无聊」；首次提交自己的行为并获实时报告解锁「研究员本人」。状态在当前浏览器中保存，不需要登录账号。

安全边界：只吐槽用户主动提交的行为和情境，不评价真实身份，不针对受保护群体，不处理他人隐私或敏感信息。边界由系统提示词强制（越界输入返回固定话术）+ 输出 JSON 校验兜底。

## 赛道创意检查

以下为团队选题提示，围绕主办方强调的独特性、趣味性和完整度展开，不是新增的必填提交字段。

- 让人意外或会心一笑的设计是什么：**「内部批注」**——报告末尾一条删除线的"研究员未删除的内部批注"，AI 的第二路输出。官方报告越一本正经，批注越真（实测样例："其实我也在刷，快睡吧。"）。
- 与普通工具或现有作品有什么具体区别：现有 AI 吐槽工具多为"毒舌评审"型、针对作品；本作针对**行为**，有统一的虚构机构世界观（案卷编号、CLASSIFIED BUT FRIENDLY 印章、成就档案），且善意克制——只吐槽行为不评人。
- AI 如何参与关键体验：AI 是报告的唯一作者。用户输入 → 系统提示词约束（人设+安全边界+JSON 契约）→ GLM-4.7-Flash 实时生成 → 客户端解析校验 → 渲染进案卷模板。没有 AI 就没有核心体验（离线档案仅为降级兜底）。
- 演示中怎样让观众看懂并体验这个创意：前 30 秒现场提交一个观众熟悉的行为（熬夜刷手机），让观众等报告生成的同时读出内部批注制造第一个笑点；随后展示成就系统与断网降级（"研究员通讯中断"也是世界观的一部分）。

## 最小版本范围（v2）

- 用户输入或起点：控制面板输入框，一句话描述自己的日常行为，上限 200 字。
- 核心操作与处理流程：提交样本 → 智谱 API 实时生成（系统提示词约束人设与安全边界）→ JSON 校验 → 渲染进案卷模板 → 计数与成就。
- 用户最终得到什么：一份含观察对象、吐槽星级、观察记录、善意吐槽、荒谬建议和「内部批注」的实时观察报告。
- AI 在哪一步产生实际价值：报告内容的唯一来源；无 AI 时仅剩离线历史档案（降级兜底，明确标注）。
- 最小版本必须实现的功能：样本输入（空输入提示）、密钥登记（BYOK，存浏览器本地）、实时生成、四态降级（无密钥/在线/中断重试/离线档案）、观察计数与两项成就、localStorage 进度保留。
- 本轮暂不实现的功能：多观察视角切换、分享海报、历史样本库展示、账号体系、服务端存储。
- 技术栈、外部服务及所需配置：原生 HTML/CSS/JS（零依赖）；智谱 BigModel OpenAI 兼容接口；模型名常量 `API_MODEL`（`api-client.js`）。无服务端密钥，无 `.env`。
- 测试用的公开或模拟数据：离线档案 7 条硬编码报告；联调用密钥由成员自带（不入仓）。
