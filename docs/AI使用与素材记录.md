## 一、项目中的 AI 使用

### 1.1 作品运行时（重要）

作品本身**不调用任何在线 AI 服务**：所有宠物回复与吐槽均来自 `game.js` 内的本地词库与预设匹配——没有 API Key、没有网络请求、断网可完整演示，页面顶栏标注「本地模拟 · 无外部接口」。

| 检查项 | 结论 |
| --- | --- |
| 运行时调用大模型 | 无 |
| 运行时联网 | 仅延迟注入 Google Fonts；失败自动退回系统字体，不影响功能 |
| 提交物含密钥 | 无（无 .env、无 API Key） |
| 音频素材文件 | 无，提示音为 WebAudio 实时合成 |

## 二、素材清单与来源

### 2.1 宠物立绘 `pets/*.png`（五张）

- 来源：团队提供的 AI 生成角色立绘（原始 2304×1728，自带 alpha 通道），经 `tools/prep-pets.py` 裁边、补白、统一到同一方形画布后入库；
- **待补填**：生成所用工具/模型、生成日期、原始出处、可公开凭据；
- 备注：角色为对市面 AI 产品（豆包 / DeepSeek / WorkBuddy / Codex / 元宝）的戏仿形象，品牌名使用尺度见 README「已知限制」与[提交前清单](提交前清单.md) D 组。

### 2.2 网页字体

- Space Grotesk、IBM Plex Mono：来自 Google Fonts，采用 SIL Open Font License 1.1；
- 仅在页面 `load` 之后异步注入；中文正文使用系统字体，未打包任何字体文件。

### 2.3 图标

- 全部图标为 `index.html` 内的内联 SVG sprite，无外部图标库文件；
- **已核对（2026-09-11）**：sprite 路径源自开源图标库 [Lucide](https://lucide.dev)（ISC 许可）的早期版本，部分图标经改写简化；Lucide 当前版本的路径已重构，因此与 sprite 不完全一致；
- 其中 `arrow-right` / `arrow-left` / `lock` / `x` / `trash-2` 等图标继承自 Feather 项目（MIT，Copyright (c) 2013-present Cole Bemis）；
- 完整版权与许可声明见仓库根目录 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

### 2.4 音效

- 无音频素材文件；点击、发送、吐槽等提示音由 WebAudio 振荡器实时合成（见 `game.js`）。
