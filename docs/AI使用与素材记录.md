## 一、项目中的 AI 使用

### 1.1 作品运行时（重要）

作品本身**不调用任何在线 AI 服务**：所有宠物回复与吐槽均来自 `game.js` 内的本地词库与预设匹配——没有 API Key、没有网络请求、断网可完整演示，页面顶栏标注「本地模拟 · 无外部接口」。

| 检查项 | 结论 |
| --- | --- |
| 运行时调用大模型 | 无 |
| 运行时联网 | 仅延迟注入 Google Fonts；失败自动退回系统字体，不影响功能 |
| 提交物含密钥 | 无（无 .env、无 API Key） |
| 音频素材文件 | 无，提示音为 WebAudio 实时合成 |

- 来源：团队提供的 AI 生成角色立绘（原始 2304×1728，自带 alpha 通道），经 `tools/prep-pets.py` 裁边、补白、统一到同一方形画布后入库；

### 2.2 网页字体

- Space Grotesk、IBM Plex Mono：来自 Google Fonts，采用 SIL Open Font License 1.1；
- 仅在页面 `load` 之后异步注入；中文正文使用系统字体，未打包任何字体文件。

### 2.3 图标

- 全部图标为 `index.html` 内的内联 SVG sprite，无外部图标库文件；
- **待确认**：是否存在借鉴自开源图标库（如 Lucide，ISC 许可）的路径；若有，在此补充许可声明或替换为自绘版本。

### 2.4 音效

- 无音频素材文件；点击、发送、吐槽等提示音由 WebAudio 振荡器实时合成（见 `game.js`）。
